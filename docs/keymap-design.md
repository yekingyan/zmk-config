# Corne 键盘 (ZMK) 键位配置设计

> 2026-03-02 整理。基于 Callum-style OSM 流派，专为 Vim 程序员 + QWERTY 基础层设计。
> 当前实现于 Lily58 上，采用"双核驱动"过渡方案。

## 设计哲学："双核驱动"过渡方案

从 104/87 键直接跳到 36 键认知陡坡太大。"双核驱动"化解了这个问题：

1. **物理冗余核（兜底）**：保留数字行、物理 Esc/Tab/Shift/Ctrl/-/'，打游戏、单手操作、大脑疲劳时提供 100% 传统肌肉记忆支持
2. **极客逻辑核（Callum-style OSM）**：核心区 3x5 隐藏了基于分层和 OSM 的终极代码输入方案
3. **3 拇指硬约束（强制塑形）**：4 个多余拇指键物理置空 `&none`，强迫手部姿态保持自然，为 Corne 36 键打肌肉基础

### 为什么选 Callum-style (OSM)

Vim 操作的灵魂是**顺序敲击**（`c-a-w`），而非**同时按住**（`Ctrl+Shift+F`）。

Home Row Mods 引入 Tapping Term 延迟，快速打字时极易误触。OSM 的优势：
- **基础层 0 延迟**：字母区纯净，按下即触发
- **拯救小拇指**：修饰键转移到左手主行 ASDF，通过"切层→短按→敲目标键"完成
- **完美契合 Vim**：所有系统快捷键变成类似 Vim 的顺序指令

### 拇指键的 Tap-Hold 妥协：One-Shot Layer

虽然我们在字母区极力避免 Home Row Mods 的触发延迟，但在拇指层键上，我们采用了 `Hold = MO, Tap = One-Shot (SL)` 的混合设计：

- **按住 (Hold)**: 持续切换到目标层（如连续输入多个数字/符号）
- **轻点 (Tap)**: One-Shot 激活目标层，按下下一个键后自动退出（适用于单次符号输入）

**设计考量**：
同一个物理按键同时提供两种层状态入口，在极少占用键位的前提下提供了极大的灵活性。虽然引入了 Tap-Hold 的判定延时（Tapping Term），但由于它只发生在拇指，并未参与字母区的高频连击，相关的心理负担和误触成本完全在可接受范围内，同时 ZMK 提供了完善的参数让我们可以调节手感。

- 左手主行 ASDF = OSM 修饰键（GUI/Alt/Ctrl/Shift）
- 左手上行 = 编辑兜底（Tab/S-Tab/Enter/Backspace）

- 右手下行 = 按词删除 + Vim 翻页 + Esc

## ZMK 实现要点

### 核心：快速释放型 OSM (skq)

```dts
behaviors {
    skq: sticky_key_quick_release {
        compatible = "zmk,behavior-sticky-key";
        label = "STICKY_KEY_QUICK_RELEASE";
        #binding-cells = <1>;
        bindings = <&kp>;
        release-after-ms = <1000>;  // 1秒内无操作自动取消
        quick-release;              // 按下任意下一个键后立刻释放修饰键
        ignore-modifiers;           // 允许连续敲击多个 OSM
    };
};
```

### J + K = Escape (Combo)

同时按下 `J` 和 `K` 触发 `Escape`，退出 Insert 模式变成潜意识动作。key-positions `<31 32>`（Lily58 矩阵）。

### Conditional Layer (Tri-layer)

NAV + SYM 同时激活 → SYS 层，无需额外拇指键。

## 进化路线图

### 阶段一：安全感过渡期（第 1-2 周）
- 打字时可依赖物理 Shift/Ctrl 和数字行
- 训练目标：适应 3 拇指分工，永远不按 4 个置空键
- 尝试遇到数字时用右拇指 SYM + 左手九宫格

### 阶段二：Callum 觉醒期（第 3-4 周）
- 主动"封印"物理冗余键
- 遇到 Ctrl+S 不再用小拇指，改用"按住左拇指 → 点 D(Ctrl) → 松拇指 → 点 S"
- 体验变化：小拇指前所未有的轻松

### 阶段三：化蛹成蝶（第 2 个月后）
- 连续几天没碰过外围一圈（数字/Shift/Ctrl/Esc）时，已具备驾驭 36 键 Corne 的全部肌肉记忆
- 随时可换 Corne
